# Kielwater

**Копитрейдинг Hyperliquid → Binance USDT-M Futures — с настоящим риск-ядром.**

*Kielwater — кильватер, след за кормой корабля. Ты идёшь в кильватере лида.*

Kielwater зеркалит позиции лид-трейдера с Hyperliquid на *твой* счёт Binance Futures в
**честной пропорции к твоему капиталу**, добавляя слой риск-менеджмента, которого нет в
биржевом копи-трейдинге. Это больше, чем копир: внутри ещё **монитор** адресов, торговый
**журнал**, веб-**панель** и инструменты **ресёрча** трейдеров.

## Чем отличается от биржевого копи-трейдинга

Биржевые копиры дают фикс-коэффициент и тупой стоп `-N%`. Kielwater даёт **риск-ядро** —
восемь фильтров в строгом порядке между «что делает лид» и «что делаешь ты»:

- **Честная пропорция** — `наш_ноушнл / наш_капитал ≈ ноушнл_лида / база_лида`, а не слепой
  коэффициент. База лида = `max(перп-эквити, спот-USDC)`.
- **Кэп плеча (гросс)** — ограничивает *суммарную* экспозицию (лид на 467% → ты на 3×). `0` =
  полный миррор без кэпа.
- **Кэп плеча на позицию** + **маржин-буфер** — никогда не занимаем 100% маржи (защита от
  Binance `-2019 Margin insufficient`).
- **Favorability-гейт** — не докупаем выше средней лида; бережём *твою* цену входа. Выходы и
  сокращения гейтом не режутся.
- **Заморозка на старте** — при подхвате не запрыгиваем в позу, где лид уже глубоко в плюсе.
- **auto-sync off** — следуем только за *новыми* движениями лида; твои ручные тримы уважаются,
  обратно не откупаются.
- **Биржа — эталон** — позиции берутся из Binance `positionRisk`, поэтому нет «призрачных» и
  «зомби»-позиций.

[`hl-copier/docs/copier-architecture.html`](hl-copier/docs/copier-architecture.html) — открой в браузере.

## Как это работает

- **Источник** — публичный API Hyperliquid (ключи не нужны): позиции, плечо, эквити лида.
- **Исполнение** — Binance USDT-M Futures, подписанный REST.
- **Размер** — честная пропорция, затем риск-конвейер, затем реконсиляция.
- **Реконсиляция** — каждый тик бот сводит *желаемое* (пропорция лида) с твоей *фактической*
  позицией и шлёт только дельту. Мейкер-первый с фолбэком в тейкер; полное закрытие всегда
  тейкером — гарантия выхода.

Полная логика: [`hl-copier/docs/COPIER-CORE.md`](hl-copier/docs/COPIER-CORE.md).

## Быстрый старт

**Требования:** Python 3.11+, Node 18+ (только для сборки панели), счёт Binance Futures с
API-ключом (фьючерсная торговля включена). Telegram-бот опционален (для алертов).

```bash
# 1. клонировать
git clone https://github.com/dilfin07/kielwater.git
cd kielwater/hl-copier

# 2. окружение python + зависимости
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

# 3. секреты — скопировать шаблон и заполнить
cp .env.example .env
#   задать: BINANCE_API_KEY / BINANCE_API_SECRET
#           TELEGRAM_BOT_TOKEN   (опц., для алертов)
#           UI_PASSWORD          (вход в панель)

# 4. конфиг — скопировать пример и выбрать лида
cp config/config.example.json config/config.json
#   targets[].address = кошелёк Hyperliquid, которого копируем;
#   настроить leverage_cap / favorability / execution_mode.

# 5. (опц.) собрать панель
cd ../ui-prototype && npm install && \
  VITE_API=live npx vite build --base=/v2/ --outDir ../hl-copier/web/v2 --emptyOutDir && cd ../hl-copier

# 6. запуск
python3 tools/serve.py --port 8787 --host 127.0.0.1
```

> ⚠️ `VITE_API=live` обязателен: без него панель собирается в **демо-режиме**
> и рисует выдуманные счёт, позиции и PnL вместо данных с бэкенда.


Открой **http://localhost:8787/v2**, войди по `UI_PASSWORD`. Начни в режиме **DRY**, посмотри
план, который строит бот, и переключись в **LIVE**, когда будешь готов.

> ⚠️ Не запускай два LIVE-экземпляра на одном счёте Binance — получишь двойные ордера.
